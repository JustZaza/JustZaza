### 🏥 MediFlow: Hospital & Pharmacy Management System

![Status](https://img.shields.io/badge/Status-In%20Progress-orange?style=flat-square&logo=hammer&logoColor=white)
![Java](https://img.shields.io/badge/Built%20with-Java-ED8B00?style=flat-square&logo=openjdk&logoColor=white)

A portfolio-scale hospital and pharmacy management system that simulates a realistic clinical workflow:

```
Patient Registration → Appointment → Check-in / Queue → Doctor Consultation
        → Prescription → Pharmacy → Dispensing → Inventory Update
```
